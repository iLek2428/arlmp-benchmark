# ARLMP Benchmark Repository

Agent-Ready Link Metadata Protocol (ARLMP) — serialization format evaluation
for Cell Nexus submission.

---

## Repository Structure

```
arlmp-benchmark/
├── codebook/
│   ├── programmatic_rules.md   ← Ground truth decision rules (commit before data collection)
│   └── power_curve.png         ← Generated by power analysis notebook
├── data/
│   ├── sampled_urls.jsonl      ← Output of 01_sample_urls.py
│   ├── resolved_urls.jsonl     ← Output of 02_resolve_and_filter.py
│   ├── shortened_urls.jsonl    ← Output of 03_shorten_via_sanst.py
│   ├── serialized_payloads.jsonl ← Output of 04_serialize_all_formats.py
│   └── adversarial_payloads.jsonl ← Output of 06_generate_adversarial.py
├── logs/
│   ├── benchmark_calls.jsonl   ← Output of 07_run_benchmark.py (one record per API call)
│   └── benchmark_summary.json  ← Aggregated metrics
├── notebooks/
│   ├── power_analysis.ipynb    ← A priori power analysis (run before data collection)
│   └── analysis.ipynb          ← Statistical analysis and figure generation
└── scripts/
    ├── 01_sample_urls.py
    ├── 02_resolve_and_filter.py
    ├── 03_shorten_via_sanst.py
    ├── 04_serialize_all_formats.py
    ├── 06_generate_adversarial.py
    └── 07_run_benchmark.py
```

---

## Execution Order

**Must run in this exact order.** Do not skip steps.

```
Phase 1 (before any data collection):
  jupyter notebook notebooks/power_analysis.ipynb
  → commit results

Phase 2 (data collection):
  python scripts/01_sample_urls.py
  python scripts/02_resolve_and_filter.py    # requires SAFE_BROWSING_API_KEY
  python scripts/03_shorten_via_sanst.py     # requires SANST_API_KEY
  python scripts/04_serialize_all_formats.py
  python scripts/06_generate_adversarial.py
  python scripts/07_run_benchmark.py         # requires API keys (see below)

Phase 3 (analysis):
  jupyter notebook notebooks/analysis.ipynb
```

## Environment Variables Required

```bash
export SAFE_BROWSING_API_KEY=your_google_safe_browsing_key
export SANST_API_KEY=your_sanst_api_key
export OPENAI_API_KEY=your_openai_key
export ANTHROPIC_API_KEY=your_anthropic_key
export DEEPSEEK_API_KEY=your_deepseek_key
```

Scripts run in dry-run mode (mock responses) when keys are absent.

## Reproducibility

- All API calls are logged with exact model identifiers and UTC timestamps in `logs/benchmark_calls.jsonl`
- Ground truth rules are fixed in `codebook/programmatic_rules.md` before data collection
- Power analysis is committed before data collection
- Random seeds are fixed (seed=42 in all sampling scripts)
